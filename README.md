# Anabolic-Steriod-Analysis# 🧬 Anabolic Steroids Data Analysis & Dashboard Visualization 

![Image](https://github.com/user-attachments/assets/00b810d3-fdeb-4c80-91c1-2a3c56cc04b8)``

This project presents an **Exploratory Data Analysis (EDA)** of a dataset containing information on various **anabolic steroids**. These synthetic compounds mimic testosterone and are often prescribed for legitimate medical conditions but are also frequently misused for performance and appearance enhancement. The dataset includes details such as each steroid's medicinal use, abuse purpose, reported side effects, molecular mass, and historical background.

Using **Microsoft Excel**, this project uncovers patterns in the data through pivot-based aggregation and visualizations, culminating in an interactive dashboard suitable for presentations or decision-making.

## 📁 Dataset Description

| Column Name              | Description                                      |
|--------------------------|--------------------------------------------------|
| Steroid Name             | Commercial/brand name of the steroid             |
| Medical Name             | Generic compound name                            |
| Medicinal Use            | Approved medical applications                    |
| Abuse For                | Common non-medical uses (e.g., bodybuilding)     |
| Side Effect              | Reported side effects (comma-separated)          |
| History                  | Background or origin of the steroid              |
| Relative Molecular Mass  | Molecular weight of the compound                 |

---

## 🧹 Data Cleaning & Preparation

- Removed empty rows, blanks, and inconsistencies
- Standardized column headers and value formatting
- Created new derived columns:
  - **Side Effect Count** (to quantify impact)
  - **RMM Category** (Low / Medium / High)
- Split multi-value fields (e.g., side effects) for more granular analysis

---

## 🧠 Key EDA Questions Explored

- What are the most common **medicinal uses** of steroids?
- What steroids are most frequently **abused**, and for what purpose?
- What are the most frequently reported **side effects**?
- Is there a relationship between **molecular mass** and **side effect frequency**?
- How do steroids used for **bodybuilding** compare with those used for **medical therapy**?

---

## 📈 Dashboard Features

- Built-in **interactive dashboard** with:
  - Slicers for **Medicinal Use**, **Abuse Category**, and **RMM Group**
  - Pivot charts (bar, column, and pie) for:
    - Side effect frequencies
    - Abuse vs medicinal uses
    - Steroids grouped by molecular mass
- All visuals are linked and dynamically filtered

---

## 🔍 Key Insights

- **Testosterone-based steroids** dominate both medical and abuse-related use.
- **Bodybuilding** and **muscle gain** are the top reasons for steroid abuse.
- **Acne, liver damage, and aggression** are the most reported side effects.
- Higher **Relative Molecular Mass (RMM)** tends to correlate with increased side effects.
